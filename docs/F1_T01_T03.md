# F1-T01..T03 — Core schema, document store, policy

Python port of `navigator-f1-core` (packages `core`, `store`, `policy`) into `shaka_server.f1`.

## Layout

- `src/shaka_server/f1/core/` — enums, dataclasses, validators, serial/BB-SB helpers
- `src/shaka_server/f1/store/` — content-addressed `DocumentStore` (blobs + meta)
- `src/shaka_server/f1/policy/` — Policy Guard v0 (`guards`, `bbsb`)
- Tests: `tests/test_f1_core.py`, `tests/test_f1_store.py`, `tests/test_f1_policy.py`

## Invariants

- **KO ≠ Asset**; **Source ≠ Evidence**
- Helpers **never invent** serial numbers (blank → `"unknown"`)
- **BB and SB never merge**
- Policy fail-closed / downgrade (invoice≠install, action≠outcome, hypothesis≠root cause, conflicted D4/D6, bounded absence for `99999999`, no topic switch, no serial guess)

Foundation Drive writes. (Search/Composer = F1-T04; Asset bootstrap = F1-T05.)
