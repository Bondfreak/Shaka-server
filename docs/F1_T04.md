# F1-T04 — Search/Retrieval + read-only Answer Composer

Deterministic retrieval and answer composition for AC-01…06 on a **frozen in-repo fixture snapshot**. No LLM. No Foundation Drive writes. Reuses F1-T01…T03 core / store / policy.

## Layout

- `src/shaka_server/f1/snapshot/` — frozen AC fixture pack (Claims, Events, Sources, Evidence, Assets, Observations, KOs)
- `src/shaka_server/f1/retrieval/` — `SnapshotIndex` keyword / part-number / side / status search
- `src/shaka_server/f1/composer/` — structured Answer + Policy Guard fail-closed/downgrade
- API: `answer_query(query: str, snapshot=...) -> Answer`
- Tests: `tests/test_f1_retrieval.py`, `tests/test_f1_composer_ac.py`

## Answer shape (EPI-001)

- **Conclusion**
- **Basis**
- **Uncertainty / Conflict**
- **Sources**
- Plus `epistemic_status`, `policy_results`, `selected_ids`, `AnswerAudit`
